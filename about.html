About this project

Each game on this site is built to be run in a real classroom first — tested, debugged, and refined against an actual session — before it's documented here. The goal is a small but growing library of tools that teach economic reasoning by having students live inside the incentives, rather than watch them from a diagram.

The first of these is The International Trade Game, a live simulation of trade policy built for ECON102 at FLAME University. More topics and games are added as they're built.
